## 使用规则

1. 先从“题面信号”判断候选模板，不要先背完整代码。
2. 每题写代码前，在题目笔记或口头说出：状态变量、窗口/循环不变量、边界。
3. 一个题可能关联多个模板，但目录中的“模板”列只写最主要的一个，避免标签失控。
4. 如果新题无法映射到本页的考试范围模板，先确认是否应纳入练习计划。
