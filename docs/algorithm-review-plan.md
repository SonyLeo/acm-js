# 算法复习推进方案

后续题目统一使用核心代码模式：`solutions/` 导出函数，`tests/` 负责构造参数和断言返回值。题目按可迁移模板连续训练，不按 HJ 编号跳跃。

## 考试范围

只安排以下内容：

- 位运算、进制转换。
- 字符串。
- 静态数组、动态数组、二维数组。
- 队列、栈、链表。
- Map、Set。
- 排序、查找。
- 枚举：遍历、排列、组合。
- 滑动窗口、双指针、前缀和。

不安排动态规划、图算法、图上的 DFS/BFS、并查集、贪心和其他范围外题目。基础排列/组合可使用回溯，但只服务于枚举训练。

## 推进顺序

### 第一组：分类、稳定排序与位置回填

1. HJ26 字符串排序：提取英文字母、忽略大小写比较、保持同字母输入顺序、回填非字母位置。
2. 数字字母混合排序变体：分类提取、数字排序、大小写分层、按原类型回填。
3. LeetCode 922 奇偶索引：分类后按索引位置回填，过渡到双指针。

完成后闭卷复写 HJ26 和混合排序变体，重点检查稳定性、字符分类和回填位置。

### 第二组：排序、查找与区间扫描

1. 区间合并：按起点排序后线性扫描，明确左闭右开边界。
2. 二分搜索：普通查找、左边界、右边界，统一使用左闭右闭模板。
3. 给定差值的组合：排序/Set 查找不重复数对，处理 `k` 与重复值边界。

### 第三组：Map/Set 与频次统计

1. 字符频次达到阈值：`Map` 统计、筛选与字典序输出。
2. HJ102 字符统计复写：频次降序、ASCII 升序双关键字排序。
3. 报文重排序：解析索引、`Map` 存储、按序拼接。
4. 呼叫转移：状态映射、后写覆盖与优先级判断链。

### 第四组：位运算与进制转换

1. HJ5 十六进制转换复写：显式进制解析。
2. LeetCode 2220 最少位翻转：异或后统计 1 的数量。
3. LeetCode 190 颠倒二进制位：固定 32 次无符号移位。
4. 魔法校验和：字节补齐、四字节大端拼接、异或与无符号输出。
5. IPv4 报文头解析：十六进制字节、位字段和大端整数。

### 第五组：字符串与数组扫描

1. HJ11 数字颠倒：字符串/数组反转与尾随零。
2. HJ12、HJ13：字符反转与单词重排。
3. 矩阵列最大值的最小值：二维数组遍历与列状态维护，安排闭卷复写。
4. 最长回文子串：中心扩展，分别处理奇偶中心。

### 第六组：队列、栈与链表

1. 基础队列模拟：数组加 `head` 指针，避免 `shift()`。
2. 基础栈模拟：括号匹配与表达式的最简优先级处理。
3. HJ51：双指针找链表倒数第 `k` 个节点。
4. HJ48：链表插入/删除的节点关系模拟。

### 第七组：枚举、滑动窗口、双指针与前缀和

1. 遍历枚举：两层循环列举数对，先建立正确性基线。
2. 排列与组合：基础回溯，明确 `path`、选择、撤销和结束条件。
3. 二进制码流最多翻转一位：窗口中非目标值不超过 1。
4. 固定长度窗口：字符串/数组的定长统计。
5. 双指针：已排序数组中的两数和或差值问题。
6. 前缀和：区间和查询与子数组和的基础题。

## 执行规则

- 每道题只创建一个核心函数文件和一个 Node 原生测试文件。
- 每题先给两个公开示例；完成后再运行本地反例测试，模拟隐藏用例。
- 每题通过后总结模板、复杂度、错误点，并给出可选的 VS Code 断点练习。
- F5 调试不是完成条件；用户自行按建议验证断点与变量状态。
- 每组完成后安排一次闭卷复写，再进入下一组。
- 旧 ACM 题保留为历史实现；只有复习需要时才创建核心模式版本。
