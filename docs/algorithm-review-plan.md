# 算法复习推进方案

后续题目统一使用核心代码模式：`solutions/` 导出函数，`tests/` 负责构造参数和断言返回值。题目按可迁移模板分组，不按题号连续跳跃。

## 总体顺序

### 第一组：分类、稳定排序与位置回填

1. HJ26 字符串排序：提取英文字母、忽略大小写比较、保持同字母输入顺序、回填非字母位置。
2. 数字字母混合排序变体：分类提取、数字排序、大小写分层、按原类型回填。
3. LeetCode 922 奇偶索引：分类后按索引位置回填，过渡到双指针。

这一组结束后闭卷复写 HJ26 和变体，重点检查稳定性、字符分类和回填位置。

### 第二组：频次统计、筛选与哈希去重

1. 字符频次达到阈值：`Map` 统计后筛选和字典序排序。
2. 给定差值的组合：`Set` 记录已见值，处理不重复数对和 `k` 边界。
3. HJ102 字符统计复写：频次降序、ASCII 升序双关键字排序。

这一组复习 `Map`、`Set`、筛选和自定义比较器的组合。

### 第三组：位运算、字节解析与进制

1. LeetCode 2220 最少位翻转：异或与统计二进制 1。
2. LeetCode 190 颠倒二进制位：固定 32 次移位。
3. 魔法校验和：字节补齐、四字节大端拼接、异或和无符号输出。
4. IPv4 报文头解析：十六进制字节、位字段和大端整数。

顺序从单个运算到完整报文解析，避免一次引入太多位操作规则。

### 第四组：滑动窗口与区间状态

1. 二进制码流最多翻转一位：窗口内非目标数量不超过 1。
2. LeetCode 995 K 连续位翻转：队列/差分状态维护有效翻转。
3. 区间合并：排序后线性扫描，明确左闭右开边界。

### 第五组：规则模拟与映射恢复

1. 呼叫转移系统：优先级判断链和后写覆盖。
2. 报文重排序：解析索引、`Map` 存储、按序拼接。

### 第六组：矩阵、字符串结构与查找

1. 矩阵列最大值的最小值：已完成本地测试，安排闭卷复写。
2. 最长回文子串：中心扩展，分别处理奇偶中心。
3. 二分搜索：左闭右闭区间、普通查找及左右边界。

## 执行规则

- 每道题只创建一个核心函数文件和一个 Node 原生测试文件。
- 每题至少包含公开样例、一个结构边界和一个容易误判的反例。
- 测试全部通过后才移除 `current-` 前缀归档。
- 每组完成后安排一次闭卷复写，再进入下一组。
- 旧 ACM 题保留为历史实现；只有复习需要时才创建核心模式版本。
