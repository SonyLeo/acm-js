# 前缀和与内存窗口练习题

## 练习顺序

本组题按以下顺序完成，不跳题：

1. 连续子数组和等于目标值的数量：前缀和 + Map。
2. 合法内存记录且总占用不超过阈值的连续子数组数量：标准滑动窗口。
3. 合法内存记录且平均占用大于阈值的连续子数组数量：前缀和进阶。

第 2 题与第 3 题都使用“元素值范围”筛掉非法内存记录。非法元素不能位于候选子数组中，因此会把数组切成互不相连的合法片段。

## 题目 1：子数组和等于目标值的数量

### 函数签名

```js
countSubarraysWithSum(nums, target)
```

### 参数与返回值

- `nums`：整数数组，可以包含正数、零和负数。
- `target`：目标整数。
- 返回：元素和恰好等于 `target` 的连续子数组数量。

连续子数组必须在原数组中连续；不同的起止下标算不同子数组，即使元素内容相同也要分别计数。

### 样例

| 调用 | 返回值 | 合法子数组说明 |
| --- | --- | --- |
| `countSubarraysWithSum([1, 1, 1], 2)` | `2` | 下标 `[0, 1]`、`[1, 2]` |
| `countSubarraysWithSum([1, -1, 0], 0)` | `3` | 下标 `[0, 1]`、`[0, 2]`、`[2, 2]` |
| `countSubarraysWithSum([2, 3, -1], 4)` | `1` | 下标 `[0, 2]` |

### 约束与练习目标

- 不使用双层循环枚举所有起止位置。
- 需要处理负数，因此不能用“和超限就缩窗”的标准滑动窗口。
- 目标是理解：当前前缀和为 `prefixSum` 时，哪些旧前缀和能与它组成目标和。

## 题目 2：合法内存记录的受限总占用窗口

### 函数签名

```js
countMemoryWindows(memory, valueRange, limit)
```

### 参数与返回值

- `memory`：非负整数数组。每项表示一个时间点的内存占用记录。
- `valueRange`：长度为 2 的数组 `[minValue, maxValue]`，表示单项内存记录允许的闭区间。
- `limit`：非负整数，表示连续时间段允许的最大总内存占用。
- 返回：满足全部条件的连续子数组数量。

一个连续子数组合法，当且仅当：

1. 它的每个元素都满足 `minValue <= value <= maxValue`；
2. 它的元素总和 `<= limit`。

`value === minValue`、`value === maxValue` 和“总和恰好等于 `limit`”都属于合法情况。空子数组不计数。

### 样例

| 调用 | 返回值 | 说明 |
| --- | --- | --- |
| `countMemoryWindows([2, 0, 1, 0, 2], [0, 2], 2)` | `10` | 所有元素值合法；统计总和不超过 `2` 的连续子数组 |
| `countMemoryWindows([2, 3, 1, 0, 2], [0, 2], 2)` | `6` | `3` 越界，任何包含它的子数组均不计数 |
| `countMemoryWindows([0, 1, 0], [0, 1], 0)` | `2` | 仅两个单独的 `[0]` 合法，验证零值处理 |

### 约束与练习目标

- 本题所有内存记录均为非负数，因此窗口总和随着右边界右移不会下降。
- 遇到元素值越界时，当前连续片段被打断；不能让候选窗口跨过该元素。
- 目标是建立标准滑动窗口的三个状态：`left`、当前窗口和、当前合法窗口的数量贡献。
- 本题是“滑动窗口 + 条件检测”。前缀和可用于验证任意区间和，但不是本题的必要实现手段。

### 边界

- 单个值刚好在范围边界，且刚好等于 `limit`。
- 单个值超出范围。
- `limit = 0` 且数组含有若干个零。
- 连续多个越界值。

## 题目 3：合法内存记录的平均占用阈值

### 函数签名

```js
countHighAverageMemoryWindows(memory, valueRange, threshold)
```

### 参数与返回值

- `memory`：整数数组，可以包含正数、零和负数。
- `valueRange`：长度为 2 的数组 `[minValue, maxValue]`，表示单项记录允许的闭区间。
- `threshold`：数值阈值。
- 返回：所有元素值均在 `valueRange` 内，且平均值严格大于 `threshold` 的连续子数组数量。

对一个长度为 `length`、元素和为 `sum` 的连续子数组，平均值条件为：

```text
sum / length > threshold
```

注意是严格大于，不包含等于。

### 样例

| 调用 | 返回值 | 说明 |
| --- | --- | --- |
| `countHighAverageMemoryWindows([2, 0, 1, 0, 2], [0, 2], 0.5)` | `10` | 值等于 `0.5` 的 `[0, 1]`、`[1, 0]` 不计入 |
| `countHighAverageMemoryWindows([2, 3, 1], [0, 2], 1)` | `1` | `3` 越界，将数组切为 `[2]` 与 `[1]` 两个片段；其中仅 `[2]` 平均值大于 `1` |
| `countHighAverageMemoryWindows([1, 1], [1, 1], 1)` | `0` | 平均值恰好等于阈值，不计入 |

### 约束与练习目标

- 先从前缀和的基础实现开始：枚举合法片段中的起止位置，通过前缀和 `O(1)` 求任意子数组和。
- 平均值条件可转换为：`sum - threshold * length > 0`。
- 不能直接照搬“总和超过阈值就移动左指针”的标准滑动窗口，因为加入或移除元素后，平均值可能上升也可能下降，不具备足够的单调性。
- 这题的目标是理解“何时滑动窗口可用、何时必须先选择更可靠的前缀和方案”，而不是强行套模板。

## 本地练习流程

每道题仍使用核心代码模式：解答文件只导出函数，测试文件负责传入参数并断言结果。

1. 先用样例手算出答案和每个连续子数组的起止下标。
2. 在解答文件中只实现指定函数，不读取标准输入，也不输出 `console.log`。
3. 为每题保留一个公开样例与两个模拟隐藏边界用例。
4. 运行对应测试：

```powershell
node --test .\tests\current-<题目名>.test.js
```

5. 三组自动测试通过后，复盘窗口不变量、复杂度和一个最容易错的边界，再移除文件名中的 `current-` 前缀归档。
