# 最大连续目标值的个数（滑动窗口闭卷复写）

## 题目描述

给定二进制数组 `bits`（元素仅为 `0` 或 `1`）和目标值 `target`（为 `0` 或 `1`）。

最多可以翻转数组中的一个元素：`0` 变为 `1`，或 `1` 变为 `0`；也可以不翻转。返回翻转后能够得到的最大连续 `target` 个数。

函数签名：

```js
maxConsecutiveTarget(target, bits)
```

- `target`：目标值 `0` 或 `1`。
- `bits`：长度为 `1` 到 `10^5` 的二进制数组。
- 返回：最多翻转一个元素后，连续 `target` 的最大长度。

## 示例

### 示例 1

```js
maxConsecutiveTarget(1, [0, 1, 1, 0, 1, 0, 1, 0, 0]) // 4
```

翻转下标 `3` 的 `0`，得到：

```text
[0, 1, 1, 1, 1, 0, 1, 0, 0]
```

下标 `1` 到 `4` 是连续的 4 个 `1`。

### 示例 2

```js
maxConsecutiveTarget(0, [0, 0, 0, 0, 0, 0, 0, 0]) // 8
```

不翻转即可，整个数组已经是连续的 `0`。

### 示例 3

```js
maxConsecutiveTarget(0, [1, 0, 1, 0, 1]) // 3
```

翻转下标 `2` 的 `1`，得到 `[1, 0, 0, 0, 1]`；下标 `1` 到 `3` 有连续的 3 个 `0`。

## 自测边界

```js
maxConsecutiveTarget(1, [1]) // 1
maxConsecutiveTarget(1, [0, 1, 0, 1, 0]) // 3
```
